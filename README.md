# Computer Connection Website  
Production Website for Computer Connection Pty Ltd  
Live Site: https://computerconnection.tech/

A fully deployed, production‑ready company website built using React, TypeScript, and Vite.  
The site serves as the public‑facing platform for Computer Connection Pty Ltd, showcasing services, contact channels, and brand identity.

## 🚀 Tech Stack
- React + TypeScript  
- Vite  
- CSS3 (responsive layout)  
- Netlify (hosting + serverless backend)  
- Netlify Forms (contact + newsletter handling)  

## 🛠 Key Features
- Fully responsive UI across desktop and mobile  
- Modular React component structure  
- Optimized production build using Vite  
- DNS, SSL, and deployment configuration  
- **Netlify Forms backend** for:
  - Contact form submissions  
  - Newsletter sign‑ups  
  - Automated email routing  
  - Spam‑protected serverless handling  

## 📦 Deployment
The site is deployed on Netlify with:
- Continuous deployment from GitHub  
- Automatic build + deploy pipeline  
- SSL certificate management  
- Domain + DNS configuration  

## 📄 Project Purpose
This website represents the official online presence of Computer Connection Pty Ltd and demonstrates:
- Modern frontend engineering  
- Production deployment workflows  
- Serverless backend integration  
- Real‑world delivery for a live business
